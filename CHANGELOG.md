# Changelog

## 0.1.0 - 2026-11-12

First release of the openedbot notch, a macOS popup for your bots.

- A small notch attached to a screen edge, with one ring per bot: run progress, approval waiting, runtime offline.
- Hover card with the bot, runtime, model, permission mode, routines and current runs.
- Agent window with the thread, inline approval (*Deny* / *Allow once*) and a composer.
- Runs on mock data by default; optional sign-in to an openedbot server (experimental).
- YOLO leases and the app update badge shown in the island.
- Hosted mode: the desktop app can embed the bundle and drive it over a JSON protocol on stdio.
- Settings pages, menu bar item and demo mode.
